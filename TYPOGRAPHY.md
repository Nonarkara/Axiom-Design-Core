# Context before type / Axiom Design Core

Typography makes a decision system legible, not merely recognisable. This is
Dr Non's practical interpretation of Robert Bringhurst, *The Elements of
Typographic Style*, supplied second edition / 1997 printing, selected close
reading. It is not a replacement for AXIOM-DNA §6, §19 or §21.

## Apply it here

1. Name the human act and choose the existing mode first. Instrument: Source
   Sans 3 for operating. Editorial: Spectral for reading. Play: the existing
   grammar with purposeful physical warmth. Do not change the approved token
   families merely because another face is less familiar.
2. Read actual labels, a paragraph, a number, a provenance line and an error.
   Map hierarchy before choosing a display face. Never hide source/age/status
   in unreadable microtext to keep the board visually quiet.
3. Proof the authorised face in its real role and medium. Distinguish 0/O and
   1/I/l; check number columns, long translated labels and actual contrast.
   Test apparent size, measure, leading and spacing together.
4. Earn a companion through a permitted role. Use only §21's sanctioned knobs;
   request a scoped exception for anything else. A serif + sans category label
   does not demonstrate structural compatibility.
5. Treat §6's uppercase/tracking rules as Latin-label policy, not a prescription
   for Thai or Chinese. Missing glyphs or unreadable script rendering require
   documented evidence and a scoped coverage exception, not silent substitution.
6. Render phone width, enlarged text and blocked fonts. Retain emphasis if a
   real cut is absent. Record the intended/actual family, licence, fallback,
   failures and pending fluent-reader review. An audit cannot certify suitability.

## Receipt required before a type change

Reader / act / mode; real text and scripts; family by role; actual cuts and
licences; alternative rejected with observed reason; size + leading + measure;
proof conditions; unresolved clipping/coverage/emphasis; approved exception;
human task and fluent-language review performed or pending.

If essential text fails, do not ship because the machine passes. Demonstrate
the failure and obtain a scoped contract adjustment. This guide grants no
automatic permission to replace the family, relax bans or change semantic colour.
